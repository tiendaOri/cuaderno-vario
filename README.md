# Cuaderno de obra Vario

Herramienta web para llevar la camperización de un camión: medidas de la caja, capas de aislante, rastreles y paneles, despiece de tableros, peso, diario de obra, archivos y gastos.

Todo funciona en el navegador y los datos se guardan en el propio dispositivo. Usa el botón "Copia" para guardar una copia de seguridad.
